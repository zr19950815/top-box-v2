# Utils 工具层

这里包含通用的工具类和辅助函数，被其他所有层使用。

## 目录结构

```
utils/
├── Logger.js          # 日志工具 - 支持多级别、多输出方式的日志记录
├── Validator.js       # 验证工具 - 参数格式验证和业务规则验证
├── CryptoHelper.js    # 加密工具 - 提供密码加密、Token安全存储等功能
└── ErrorTypes.js      # 错误类型定义 - 标准化的错误类型和错误处理
```

## 设计原则

- **通用性**：工具类必须是通用的，不包含业务逻辑
- **无依赖**：工具类之间尽量避免相互依赖
- **高质量**：工具类要经过充分测试，保证稳定性
