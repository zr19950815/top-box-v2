# Processors 处理器层

这里包含业务处理器，负责抽象化常见的业务逻辑处理。

## 目录结构

```
processors/
├── payment/
│   └── PaymentProcessor.js   # 支付处理器 - 统一的支付流程处理
├── order/
│   └── OrderProcessor.js     # 订单处理器 - 统一的订单状态检查和处理
└── StatsCollector.js         # 统计收集器 - 任务执行统计和监控
```

## 设计原则

- **统一处理**：将不同平台的相似逻辑抽象为统一处理流程
- **可复用**：处理器可以被不同策略和平台复用
- **单一职责**：每个处理器只负责一类特定的业务逻辑
