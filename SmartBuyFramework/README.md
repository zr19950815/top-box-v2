# SmartBuy Framework

高度抽象的多平台智能购买框架，专为自动化抢购而设计。

## 项目结构

```
SmartBuyFramework/
├── core/                 # 核心框架层（完全抽象）
├── processors/           # 处理器层（完全抽象）  
├── interfaces/           # 接口定义层（完全抽象）
├── platforms/            # 平台适配层（唯一包含平台逻辑）
├── utils/                # 工具层（完全抽象）
├── test/                 # 测试文件
├── cli.js                # CLI入口
├── main.js              # 程序入口
└── package.json         # 项目配置
```

## 核心特性

- **🎯 多平台支持**: 统一接口支持多个电商平台
- **⚡ 多种策略**: 列表、快捷、批量三种抢购模式
- **🔧 易于扩展**: 新增平台只需实现8个标准方法
- **🔐 智能认证**: 自动Token管理，无需手动处理登录
- **📱 简单易用**: 一行指令即可开始抢购
- **🛡️ 稳定可靠**: 完善的错误处理和重试机制

## 快速使用

```bash
# KyArt平台列表模式抢购
node cli ky列表-手机号-pwd123-pay123-529*5*128

# HzMiss平台快捷模式抢购  
node cli hz快捷-手机号-pwd456-pay456-510200003*2*15

# 合成确认
node cli ky合成-手机号-pwd123-pay123-combo123
```
