## 🚀 SmartBuy Framework 简介

SmartBuy Framework是一个高度抽象的多平台智能购买框架，专为自动化抢购而设计。

### ✨ 核心特性

- **🎯 多平台支持**: 统一接口支持多个电商平台
- **⚡ 多种策略**: 列表、快捷、批量三种抢购模式
- **🔧 易于扩展**: 新增平台只需实现12个标准方法
- **🔐 智能认证**: 自动Token管理，无需手动处理登录
- **📱 简单易用**: 一行指令即可开始抢购
- **🛡️ 稳定可靠**: 完善的错误处理和重试机制

### 🏗️ 架构优势

```
用户指令 → 框架解析 → 🆕自动认证 → 平台适配 → 策略执行 → 支付完成
     ↓
统一的API接口 + Token自动管理 + 可扩展的平台支持 + 智能的策略选择
```

### 📱 使用示例

```bash
# KyArt平台列表模式抢购
node cli ky列表-手机号-pwd123-pay123-529*5*128

# HzMiss平台快捷模式抢购  
node cli hz快捷-手机号-pwd456-pay456-510200003*2*15

# 合成确认
node cli ky合成-手机号-pwd123-pay123-combo123
```

## 📋 用户使用指南

### 安装和配置

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd smartbuy-framework
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动程序**
   ```bash
   node cli <指令>
   ```

### 指令格式

基本格式：`<平台><任务>-<账号>-<密码>-<支付密码>-<参数>`

#### 抢购任务
```bash
# 列表模式：刷新列表 → 筛选最优商品 → 下单
node cli <平台>列表-<账号>-<密码>-<支付密码>-<商品ID>*<数量>*<最高价格>

# 快捷模式：直接调用快捷下单接口
node cli <平台>快捷-<账号>-<密码>-<支付密码>-<商品ID>*<数量>*<最高价格>

# 批量模式：调用批量下单接口
node cli <平台>批量-<账号>-<密码>-<支付密码>-<商品ID>*<数量>*<最高价格>
```

#### 简单任务
```bash
# 合成确认
node cli <平台>合成-<账号>-<密码>-<支付密码>-<合成ID>

# 取消寄售  
node cli <平台>取消-<账号>-<密码>-<支付密码>-<寄售ID>
```

### 项目结构
```
SmartBuyFramework/
├── core/                 # 核心框架（完全抽象）
├── processors/           # 处理器（完全抽象）  
├── interfaces/           # 接口定义（完全抽象）
├── platforms/            # 平台适配（唯一包含平台逻辑）
├── utils/                # 工具类（完全抽象）
├── doc/                  # 文档
├── test/                 # 测试文件
├── cli.js                # CLI入口
└── main.js              # 程序入口
```

### 关键原则

1. **分层清晰**: 只有`platforms/`目录包含平台相关逻辑
2. **接口标准**: 所有平台必须实现相同的8个标准方法
3. **策略统一**: 所有抢购策略共享相同的流程控制
4. **扩展简单**: 新增平台只需要3个步骤

## 🌟 添加新平台

想为框架添加新的购买平台？按照以下步骤：

### 快速步骤

1. **创建适配器** - 继承`PlatformAdapter`并实现8个方法
2. **定义指令** - 创建指令映射文件
3. **注册平台** - 在`main.js`中注册平台

详细教程请参考：[平台接入指南](./platform-integration-guide.md)

### 需要实现的方法

```javascript
// 抢购相关（4个方法）
async getProductList(productId, options)
async placeOrder(product)  
async quickOrder(productId, quantity)
async batchOrder(productId, batchSize)

// 支付相关（2个方法）
async getPaymentUrl(orderInfo)
async executePayment(paymentUrl, password)

// 简单任务（2个方法）
async confirmCombination(combinationId)
async cancelResale(resaleId)
```

## ❓ 常见问题

### 用户问题

**Q: 支付失败怎么办？**  
A: 检查支付密码是否正确，余额是否充足，如果问题持续请检查平台是否有安全验证。

**Q: 为什么找不到符合条件的商品？**  
A: 检查最高价格设置是否合理，商品ID是否正确，或者当前确实没有符合条件的商品。

**Q: 如何停止运行中的任务？**  
A: 使用 Ctrl+C 可以优雅停止任务，框架会显示执行统计。

### 开发者问题

**Q: 如何调试平台适配器？**  
A: 使用适配器的测试方法，或者增加日志输出来跟踪API调用过程。

**Q: 新平台的支付流程很复杂怎么办？**  
A: 在`executePayment`方法中实现完整的支付流程，可以参考KyArt的复杂支付实现。

**Q: 平台API变更了怎么办？**  
A: 只需要更新对应平台的适配器，不影响框架和其他平台。
